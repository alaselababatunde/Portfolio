# TescoSupportRAG

TescoSupportRAG is a Retrieval-Augmented Generation (RAG) demo built using real-world Tesco Online Grocery FAQs.

## Dataset
The assistant uses approximately 100 frequently asked questions compiled from Tesco Online Grocery help pages (August 30, 2023).

## Features
- Semantic FAQ retrieval
- Sentence-transformer embeddings
- Simple Gradio interface
- Hugging Face Spaces compatible

## Use Cases
- Customer support chatbot demos
- FAQ search systems
- RAG learning projects

## Disclaimer
This project is for educational and experimental purposes only and is not affiliated with Tesco.
